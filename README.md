# LaserPrep — релизы

Готовые сборки **LaserPrep** — программы для Windows, которая готовит изображения к лазерной гравировке: коррекция и дизеринг под материал, AI-обработка (удаление фона, апскейл, колоризация, карты глубины), экспорт в PNG, BMP, SVG, DXF, STL. Работает офлайн, интерфейс на русском, английском и китайском.

В этом репозитории только релизы программы — исходного кода здесь нет.

## Скачать

Последняя версия — [Releases → Latest](https://github.com/DimZol/laserprep-releases/releases/latest).

| Архив | Для какой системы |
|---|---|
| `LaserPrep-<версия>-win-x64.zip` | Windows 10 и 11, 64 бита — основная сборка |
| `LaserPrep-<версия>-win7-x64.zip` | Windows 7 SP1, 8 и 8.1, 64 бита — те же функции; AI-модели считаются на процессоре через WebAssembly, примерно в 3–5 раз медленнее |

## Установка

1. Распакуйте архив в любую папку.
2. Запустите `LaserPrep.exe` в папке `LaserPrep-win32-x64` (или `LaserPrep-win7-x64`).
3. AI-модели скачиваются в самой программе: Настройки → AI-модели.

Без лицензии программа работает 3 дня в пробном режиме. Лицензия подходит к обеим сборкам.

## Обновления

Программа сама проверяет этот репозиторий при запуске (отключается в Настройках → Обновления) и по кнопке «Проверить сейчас». Если вышла новая версия, она предложит открыть архив своей сборки. Установка: закройте LaserPrep и распакуйте новый архив на место прежней папки — лицензия, настройки и скачанные модели сохранятся.
